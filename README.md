# TextPin

TextPin keeps short notes pinned on your screen.

A phone number, a parking spot, the next step of a task: press one shortcut, type it, and the note stays where you can see it. When you need the space, hide every note at once; when you need one back, find it in seconds.

## Quick start

1. Open TextPin. It lives in the menu bar (the system tray on Windows and Linux), not in the Dock.
2. Press **⌘F2** (Ctrl+F2 on Windows and Linux). A note appears next to your mouse; type what you want to keep.
3. Click outside the note when you're done. Now drag it anywhere, and scroll on it to make it bigger or smaller.
4. Choose **Open TextPin Management** from the menu bar icon to search, edit, restore or delete notes.

## Moving and resizing notes

A note you are typing in keeps the mouse for editing: dragging selects text and scrolling scrolls the text. Hold **⌘** (Ctrl on Windows and Linux) to move or resize it anyway.

| | Note you are typing in | Any other note |
| --- | --- | --- |
| Move | ⌘-drag | Drag |
| Resize | ⌘-scroll | Scroll |

Each scroll step changes the size by 10%; set the step in Settings → General → Zoom speed.

## What you can do

- Pin a note with one shortcut; each note gets its own colour.
- Keep a note always on top, or let it sit behind other windows.
- Hide all notes and bring them back in one step.
- Search every note, including hidden ones, in the management window, and select several to show, hide, copy or move to the Trash together.
- Move between notes with ⌘\` (Ctrl+\` on Windows and Linux).
- Change the shortcuts, zoom step, language (English, 简体中文) and light or dark appearance in Settings.
- Get updates inside the app (Settings → General → Updates).

TextPin is free to use. Pro adds features such as showing a note on every desktop (macOS Spaces) and more Workspaces; see the [website](https://printf.app/textpin/#pricing).

## Download

Download the latest release for your platform from [GitHub Releases](https://github.com/printfapp/TextPin/releases/latest).

| Platform | Package |
| --- | --- |
| macOS Apple Silicon | `aarch64` DMG |
| macOS Intel | `x64` DMG |
| Windows 10/11 | `.exe` or `.msi` |
| Linux x64 | `.AppImage` or `.deb` |
| Linux ARM64 | `.AppImage` or `.deb` |

The macOS Apple Silicon and Intel packages are separate downloads. Choose the one that matches your Mac.

### First launch

- **macOS:** If macOS shows a Gatekeeper warning, right-click the app and choose **Open**.
- **Windows:** If SmartScreen appears, choose **More info** and then **Run anyway** when you trust the downloaded release.
- **Linux:** Make the AppImage executable before launching it: `chmod +x TextPin_*.AppImage`
